屏译 · 悬浮翻译器（Screen Translate）
=====================================

一、这是什么
  一个常驻桌面的小悬浮翻译器：点“框选翻译” → 框住屏幕上的任意文字 → 自动识别(OCR) →
  在线翻译 → 识别到的每一行文字，都会在**原页面对应位置直接盖一行译文**（原位标注，不截图）。
  不用截图、不用跳到网页里粘贴。

二、环境要求
  · Windows 10/11
  · Python 3.10+（需带 tkinter；python.org 官方安装包默认带）
  · 依赖：pip install -r requirements.txt
  · 首次识别文字会联网下载 OCR 模型（十几秒），之后可离线识别；翻译需联网。

三、安装与启动
  1) 安装依赖：pip install -r requirements.txt
  2) 启动（三选一）：
     a. 双击「启动悬浮翻译.vbs」（无黑框）。脚本优先用 C:\Python314\pythonw.exe，
        不存在则用系统 PATH 里的 pythonw.exe。
     b. 命令行：pythonw screen_translate.py
     c. Python 装在别处时，编辑 .vbs 第 7 行的 py 路径即可。
  3) 依赖装在哪个 Python，就用哪个 Python 启动；两者要一致。

四、界面与操作
  · 正常状态：显示「框选翻译」「展开 ▾」「收起」三个按钮，尽量短小。
  · 展开 ▾：展开后出现 源语言 / 目标语言 / 识别语言 / 透明度 / 停留 / 其他语言 / ×；「收起」就在「展开」旁边。
  · 框选翻译：屏幕变暗，拖动鼠标框选要翻译的区域；松开即识别并翻译，Esc 取消。
  · 透明度：同时调整悬浮框和译文卡片的透明度；调低可透出底下原页面（同屏对照）。
  · 右键拖动：使用状态下，按住工具栏任意处用右键拖动即可改变位置（位置会记住）。
  · 收起：收成贴在屏幕左侧的圆球（“译”），只能上下拖动；点一下球（或右键）展开。
  · 译文浮层：识别到的每一行文字，都会在它原来的位置盖一行译文（不截屏、不聚成一个大窗）；
    左键点浮层可复制该行译文，右键关闭该行；「透明」调节所有浮层透明度。
  · 浮层自动消失：默认停留 10 秒后自动清除（展开面板「停留」可调 3–60 秒）；
    按 Esc 立即清除；切换窗口、点「收起」、重新框选也会清除，不会一直挡在页面上。

五、翻译引擎
  · 默认 MyMemory（国内可直连，支持自动检测源语言），失败自动切 Google。
  · MyMemory 匿名免费额度约 5000 字/天；用尽当日可能失败，会给出状态提示。
  · 上次成功的引擎会记到 config.json。

六、语言包：翻译成更多语言
  · 目标语言已内置 中/英/日/韩/法/德/西/俄/阿/意/葡/泰/越/荷/波/瑞典/丹麦/芬兰/捷克/希腊/匈牙利/罗马尼亚/乌克兰/希伯来/印地 等。
  · 想翻成别的语言：点「其他语言」添加该语言（填代码+名称），再在“目标”下拉框选它。
  · 也可在「其他语言」里填“代码+名称”点添加 → 写入 langpacks.json，重启仍在。
  · 语言代码用 ISO 639：en/ja/ko/fr/de/es/ru/ar/it/pt/th/vi/nl/pl/sv/da/fi/cs/el/hu/ro/uk/he/hi …。

七、OCR：识别更多种类的文字（一步步）
  说明：内置识别模型只认“中文+英文”。日/韩/俄等非中英文字默认识别不出——这是
  “只支持中英文”的真正原因（翻译引擎其实支持很多语言，卡在“认字”这一步）。
  想识别这些文字，按下面做：
    1) 到 RapidOCR / PaddleOCR 模型库，下载“对应语言的识别(rec)模型”（.onnx）。
       建议选自带字符字典的 PP-OCR rec 模型。
    2) 在程序目录新建文件夹 models，把模型放进去并命名为 rec.onnx：
         D:\doubao pingyi\models\rec.onnx
    3) 重新启动程序。程序检测到该文件就自动用它识别；没有就用内置中英模型。
    4) “识别语言”下拉框保持默认即可（识别模型已换成你下载的语言）。
  提示：检测(det)模型是通用的，无需更换，只换 rec 识别模型即可。

八、常见问题
  1) 双击没反应：查看同目录 error.log，多为 Python 路径不对或缺 tkinter。
  2) 缺 tkinter（Tcl/Tk 报错）：换用 python.org 官方完整安装包。
  3) 翻译失败 403/429：MyMemory 额度/限流，或 Google 限流；等一会或换网络。
  4) 框选区域没反应/太小：至少拖出 8×8 像素。
  5) 仅支持主显示器框选。

九、文件说明
  · screen_translate.py      主程序
  · 启动悬浮翻译.vbs         双击启动（无黑框）
  · requirements.txt         依赖清单
  · config.json              上次成功的翻译引擎（自动生成）
  · langpacks.json           你添加的语言包（使用后自动生成）
  · error.log                出错日志（出错时生成）
  · models/rec.onnx          可选：自定义识别模型（自己放）
